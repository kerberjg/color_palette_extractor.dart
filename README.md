### 💙 Use cases

- 🪩 **Party lights**: set party lighting to match music cover art (& animate to music tempo)
- 🎨 **Art projects**: match the ambient lighting to displayed artwork
- 🏡 **Home automation**: use the bundled HTTP server to integrate color palette extraction into Home Assistant automations

## ✨ Features

- Extracts dominant color palettes from images
- Configurable palette size
- Fast: 512x512 image processes in `75ms` (tested on Apple M4)
- Supports GIFs and multi-frame images
- Uses `OKLCH` color space for accurate color representation
- Discards transparent pixels

- **More configuration options** for customizing the color extraction process
